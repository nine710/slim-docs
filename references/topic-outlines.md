# Topic outlines (task/domain slots)

Not mandatory filenames — pick slots that match the repo. Each file starts with:

# <slug>

Read when: ...
Out of scope: ...

## Invariants / hard rules
## Key paths
## Do / Don't
## Verify
## Notes

## low (2-3)

1. architecture-map.md — modules and where to edit
2. commands-and-verify.md — build/test/lint and done evidence
3. optional conventions.md — style and bans

## medium (4-8)

All low, plus:
- 2-4 domain slots from real packages (e.g. auth.md, billing.md)
- testing.md
- gotchas.md

## high (8-20)

More domain slots; optional subdirs for storage (agent-docs/payments/foo.md) with paths still listed in the root index.
